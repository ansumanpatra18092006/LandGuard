# LandGuard Advanced AI Patch

This patch upgrades the current PAIMANA intelligence screen without changing the project/auth/GIS architecture.

## Added

1. **Probability calibration**
   - The selected Random Forest remains the base classifier.
   - A Platt-style calibrator is fitted on the January 2026 validation month only.
   - The held-out February 2026 month remains untouched until final evaluation.
   - `probability_calibrator.joblib` is generated by retraining.

2. **Historical analogues**
   - Every project prediction is compared with the nearest real PAIMANA snapshots from the model-development period.
   - The UI shows the closest cases, similarity, and whether each case slipped within the next 3 months.
   - The held-out February test rows are excluded from the analogue pool.

3. **Scenario Lab**
   - Officers can vary hypothetical expenditure progress and rerun model sensitivity.
   - This is explicitly labelled as a sensitivity scenario, **not causal evidence**.

4. **Threshold-aligned risk bands**
   - LOW: below 30%
   - MEDIUM: 30% up to the trained alert threshold
   - HIGH: at/above the trained alert threshold
   - `Slip alert` and `Risk category` therefore no longer contradict each other.

## Apply

Extract this ZIP directly into `C:\LandGuard`.

Then retrain locally so the model + probability calibrator use your installed scikit-learn version:

```powershell
cd C:\LandGuard\backend
python -m app.ml.train_paimana
```

Restart backend:

```powershell
uvicorn app.main:app --reload
```

Restart frontend if necessary:

```powershell
cd C:\LandGuard\frontend
npm run dev
```

No database migration is required for this patch.
